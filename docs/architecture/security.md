# 安全与隐私边界

本文件为必须实现的安全门禁，不是已通过安全审计。参考原站有账号内容并不授权公开账号资料；本产品不实现原站账户系统。

## 威胁与对策

| 风险 | 实施要求/负例 |
|---|---|
| 前端泄漏钥匙 | 仅服务端credential vault；secret字段write-only；禁止VITE_*、URL/localStorage、bundle/log/screenshot/fixture/export含钥匙；配置操作日志脱敏 |
| localhost跨站请求/重绑定 | loopback绑定、Host/Origin严格允许清单、会话授权/HttpOnly cookie、CSRF token；初始化会话仅受控本地启动授权，不接受任意跨站cookie创建/状态更改；单用户无注册登录但API仍有访问控制 |
| 供应商任意代理/SSRF | 标准Provider固定官方域名与协议；自托管配置显式登记，私网允许仅该Provider可信baseURL；URL素材抓取拒绝loopback/私网/metadata/DNS重绑定与重定向到禁止地址；每跳复验、限制大小/时间，不带钥匙抓任意URL |
| 文件系统/压缩包攻击 | 路径由服务端生成、受控数据根目录；拒绝../、绝对路径、symlink越界、zip bomb；fileName仅显示名；原始上传限额/媒体解析隔离 |
| shell注入/媒体资源耗尽 | ffmpeg等参数数组不拼shell；受限并发/超时/临时目录/磁盘空间；拒绝不受支持格式，解析失败不执行任意代码 |
| 任务重复计费 | 本地意图去重；远端幂等仅有文档证明时采用；提交超时unknown不重发；成本/预算并发原子，取消不假退款 |
| Agent提示注入 | 内容不提升工具权限；只typed工具；无任意shell/系统读写/公开发布；密钥不进入上下文；费用与声音/肖像许可确认 |
| 加密伪安全 | 会话内存默认；持久钥匙经OS钥匙串或用户主口令；密钥不能与密文同目录明文保存；备份默认无秘密；丢主口令明确不能恢复 |
| 发布隐私/版权 | research保持忽略；公开fixtures合成且有权使用；第三方字体/Logo/音视频无授权不打包；git/构建/Docker context/日志/截图全部检查 |

## 默认隐私

无遥测、无公共上传/分享。外部推理前明示哪些输入发送给哪个Provider；供应商可能保留/训练数据，不能承诺本地UI等于供应商零保留。官方零保留能力有方案条件；不绕过。

LAN/多人部署不是首发默认；不得把绑定0.0.0.0当作解决访问失败的方法。Docker映射也需显式loopback。Provider可用≠秘密安全，发布前需验证本表所有负例并记录证据。
