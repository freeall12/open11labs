# 数据与文件组织

提案：SQLite存元数据/工程/任务/事件/成本/偏好，文件系统存资产与导出，钥匙存独立vault。尚未实现，具体schema由CORE/STORAGE依共享契约维护，不在PRD贴DDL。

## 对象关系

Project版本引用Asset；Job快照引用输入Asset与模型配置并产生输出Asset；UsageEntry关联Job/Provider；Credential只由服务端通过ref读取，工程不嵌入秘密。单用户本地没有云成员/角色模型。

## 运行目录（私有）

`data/db/`、`data/assets/`、`data/tmp/`、`data/exports/`、`data/backups/`、`data/secrets/`，均Git忽略。每次任务目录采用服务端生成ID，不能用prompt/文件名作路径。不得向前端直接暴露绝对路径。临时文件完成/取消后回收，但不能删除仍被任务使用的文件。

## 一致性与恢复

- 保存采用事务/原子文件替换；任务提交前落本地intent，远端接受后落requestId；进程崩溃在二者之间时标未知，不能自动重发。
- 本地job、远端job、导入输出三个阶段分别持久化；产物下载失败重下同一结果，不重生成。
- revision冲突提示合并/保存副本，不能无声覆盖另一标签页。
- schema/version迁移先备份，校验兼容/失败回滚；fixtures含旧工程版本。
- 删除工程不默认删除所有共享资产；删除资产检查引用，提供明确断链影响；永久删除需要确认。
- 导出bundle包含工程schema版本、相对资产路径、模型/许可来源和必要任务结果，不含密钥/raw研究/绝对路径。
- 恢复测试覆盖重启、损坏db/缺文件、磁盘满、迁移失败/备份导入、孤立文件清理；恢复不调用付费生成。
