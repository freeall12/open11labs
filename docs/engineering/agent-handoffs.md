# Agent接力与交接

由操作者决定是否启动其他Agent；本文件不自动授权委派。不在同cwd同时多writer。接手先读根AGENTS、SCOPE、任务表、git diff/分支和已有状态；不覆盖用户/其他Agent改动。

## 领取与检查点

选择任务ID，记录owner、文件写入范围、起始commit、依赖状态、预计输出和风险。每个可验证里程碑更新完整计划，只有一个in_progress；合同变更通知依赖角色，先类型/fixture后页面。未知付费状态、外部授权、资源许可或无法补采属于阻塞，不自行越权处理。

新框架/大规模迁移/真实API预算/永久删除/发布/克隆/设备授权需要操作者批准。普通可逆实现与本地mock测试按任务自主推进，不能因为某一API权限未知停止所有其他工作。

## 每次交接模板

```markdown
# 任务 Mx-Txx 交接
- 角色/工作目录/分支/起始与结束commit
- 需求/验收ID
- 本次改变的路径及契约版本
- 已实现操作（逐项）与截图/日志/产物
- 测试命令、退出码、环境；真实/mock/文档验证分别标注
- 是否修改Provider/模型/费用/持久化/秘密处理
- 排除范围检查（营销/账户无入口/占位）
- 未完成/未运行/失败/阻塞及下一步
- 残余风险/用户需要确认的DID
```

保存到 `docs/engineering/handoffs/<task-id>.md`（角色自行新建）。任何报告不得含原账号邮箱/秘密/raw研究复制；只引用本地证据ID。Goal Mode中断时写同样检查点，不用“已完成”结束未完成任务。
