# 发布门禁（尚未执行）

开源代码发布与部署运行分开；本轮没有自动push、release或发布包。最终交付必须遵守用户排除原站营销/账户的要求。

- [ ] in-scope路由/逐控件清单与分层验收有实际证据，所有缺口/例外明确，不把mock算真实能力。
- [ ] 无营销/头像/账户/云成员/套餐/余额/收益页面及入口；旧路径无账户UI。
- [ ] typecheck/build、单元/契约/集成/E2E/视觉运行记录；效果/体验协议及未决事项明示。
- [ ] 干净机器启动、loopback/API同源、端口/数据持久/重启/迁移/备份恢复验证。
- [ ] 秘密检查Git历史/工作树/bundle/log/fixtures/Docker context；无raw研究/账号标识/未授权资产。
- [ ] 密钥write-only/加密、Host/Origin/CSRF/SSRF/文件路径/Agent工具权限负例通过。
- [ ] Provider文档/SDK锁定、许可与模型权限/成本未知说明；不绕过套餐/审批，不制造退款。
- [ ] D2许可证/名称/资源权利确认；第三方通知与合成示例来源明确。
- [ ] README真实运行命令、配置/故障/支持OS与已知限制完整；无不存在的Docker/test命令。
- [ ] 用户授权后再发布，附版本/变更/安全说明；不上传私有研究/钥匙。

任何未完成项记录为阻塞或明确延期，不能宣布完整1:1或100%真实功能完成。
