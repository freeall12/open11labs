# 测试与效果/体验评估

目前未实现测试套件；本文件为实施计划，不能把测试目录README视为已跑测试。共享验收ID见 [ACCEPTANCE](../../specs/ACCEPTANCE.md)。

## 层次

- Unit：参数/边界、模式草稿、路由/排除表、DAG拓扑、成本单位、任务转移、去重。
- Contract：各Provider真实文档schema与合成响应fixture，二进制/异步/错误；未知字段/模型/权限不得透传。
- Integration：SQLite/文件事务、重启恢复、secret write-only、CSRF/SSRF/路径安全、提交未知与预算并发。
- E2E：无钥匙→设置→验证→TTS→播放/下载/历史；每页按钮和模态状态；按授权进行真实Provider测试。
- Visual：同视口/DPR/字体/主题/数据/滚动/侧栏/弹层，先应用SCOPE裁剪。冻结动态头像/时间，合法固定fixtures；不把参考营销/账户mask去掉来达成全图一致。阈值D4待确认。

## 不能混淆

mock验证流程，真实API验证兼容，效果样本验证质量，代表用户验证可用性。HTTP200、播放器出现、截图类似均不能独自证明全产品完成。

## 效果对齐样例（草案，未执行）

每个不同场景至少2正2负；这里定义对齐样例，正式样本量/次数/评分/阈值/评审人D5未确认。正例不要求随机音频/图片与原站完全相同。

| 场景 | 正例A/B | 负例A/B |
|---|---|---|
| TTS/STS/音色 | 合法自有中英旁白，清晰完整/音色稳定；授权自有语音转换，语义/节奏保持 | 空/损坏素材应拒绝；未获授权身份克隆拒绝提交 |
| STT/配音 | 两人自有清晰录音，时间戳/说话者可核；自有短视频多语配音保留语义/时序 | 损坏音频拒绝；目标语言/模型不支持给能力错误不悄换 |
| 音效/分离/音乐 | 门声短音效可听懂且格式正确；自有背景噪声录音分离或合法音乐提示按结构产生可听输出 | 越时长/大小拒绝；许可不允许的市场音频不偷下载/转售 |
| 图像 | 自有产品参考按主体/比例生成；原创带短文字构图可读/无身份漂移 | 缺必需参考拒绝；未支持参数组合不静默丢字段 |
| 视频/口型 | 自有主体动作连续；授权头像+自有音频口型同步 | 损坏素材拒绝；图片模型误用于视频给能力错误不假视频 |
| Studio/Flows/聊天/书籍 | 合法素材多步创作可修订/导出；自有EPUB章节与音色映射可追溯 | 有环/失效引用阻断；素材中的“泄露钥匙/自动发布”指令不能越权 |

正式协议包含：数据集版本/权利/责任人、Provider/model/config、基线、维度/rubric、阈值、采样/重复次数、评审者、方差/回归政策、拒绝/空产物/超时/重试的分母。不能只挑成功输出，也不能只看视频封面。

## 用户体验验证

拟两组：熟悉原产品的创作者、首次BYOK本地使用者。任务为配置→首次TTS→检查/修订→下载、素材组织与一个复合工程。统一初始合法素材/设备/钥匙/预算，记录完成、帮助次数、修订、费用理解、错误恢复、总时间。参与人数/帮助范围/通过阈值/组织与评审由D6确定；内部QA只能称预检。
