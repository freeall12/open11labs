# 检查点 2026-10-03 · 人声分离页

## 本次变更

`/app/voice-isolator` 从占位页换成真实实现。**未调用任何 Provider**。

## 上传限额不合并（规范硬要求）

`docs/pages/voice.md` 明确写了三个不同的数字，且禁止合并成一个全局限额：

| 工具 | 数字 | 来源 |
|---|---|---|
| 变声器 | 50MB | 网页观察 |
| **人声分离** | **500MB / 1 小时** | 文档观察 |
| 语音转文本 | 1000MB | 网页观察 |

本页只显示自己的 500MB/1h，并明写「**未经 API 验证**」以及
「这个数字只属于人声分离，不适用于变声器或语音转文本的上传限制」。

适配器层同样不做强制——只拒绝空文件，真正的上限交给 Provider 判定。

## 计量方式也不换算

文档说「每分钟 1000 字符」，但未经真实调用核验，所以本地**不把它折算成金额**，
一律记为「费用未知」。

## 能力边界

页面开头写明：人声分离用于**去除背景噪声**，**不是**音乐分轨或乐器分离。
这是很容易被误解的能力，写在前面而不是藏起来。

## 测试抓到的问题

测试桩只实现了 `submit`，隔离路径走的是 `submitIsolation`，
导致桩漏接。已改为转发全部适配器入口——这类桩缺陷会让**未被桩覆盖的路径
假装通过**。
