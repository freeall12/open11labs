## 实现的状态（截图验证）

| 状态 | 行为 |
|---|---|
| 未配置 Provider | 生成按钮禁用，提示去本地设置；**不静默禁用**，给出原因 |
| Provider 非 available | 显示其状态与错误，链接到验证页 |
| 能力未核验 | 明示所有模型为「未验证」，不替你断言可用 |
| 文本为空 | 「请输入要朗读的文本」 |
| 接近上限 (>90%) | 琥珀色提示 |
| 正好等于上限 | 独立文案，不与"超限"混淆 |
| 超出上限 | 红色提示 + 禁用生成 |
| 参数不适用于当前模型 | 滑块置灰 + 「当前模型不支持该参数，不会发送。」 |
| 输出格式需更高权限 | 明示"需更高权限，未核验" |
| 未勾选费用确认 | 生成按钮禁用 |
| 费用 | 始终记为「未知」，**不显示 0** |

## 关键设计

**意图去重落在 UI**：intentId 由 `provider+model+voice` 派生，重复点击返回同一
本地任务，不会二次计费。

**参数按模型过滤**：提交前剔除当前模型不支持的字段，而不是发给远端再被拒。
切换模型丢弃不兼容字段但**保留草稿文本**（规范要求）。

**音色不静默替换**：音色搜索/筛选接口尚未接入，页面直接接受 API 音色 ID 并说明
原因，不会悄悄换成别的音色。

**确认内容包含数据去向**：勾选项写明"同意向 {baseURL} 发送上述文本"。
