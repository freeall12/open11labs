# 检查点 2026-10-03 · 图像/视频/口型同步页面

## 本次变更

`/app/image-video` 从占位页换成真实实现，支撑上一检查点加的异步路径。
**未调用任何 Provider**。

## 模态走 URL

三种模态由 `?modality=` 决定（image / video / lipsync），与 `routes.json`
里三条 mode-query 路由一致，所以深链能直接落到正确模态：

- 切模态重置无效模型，但**保留描述草稿**（草稿不因模态切换被丢弃）
- `jobsApi.poll()` 做轮询，带**递增退避**（2s 起，随次数加长）
- 最多 40 次后停止，避免热循环打付费接口

## 状态

| 状态 | 行为 |
|---|---|
| 未配置 Provider | 按钮禁用 + 链接到本地设置 |
| 描述为空 | 按钮禁用 + 原因 |
| 模型需账户审批 | 明示"本地无法代为申请"，并禁用 |
| 未勾选费用确认 | 按钮禁用 |
| 远端执行中 | 显示本地任务 ID **与远端任务 ID**，说明关闭页面不丢任务 |
| 产物 | 图片用 `<img>`、视频用 `<video>`，均提供下载 |

## 审批类模型的处理

部分模型（如部分 ByteDance）在 Provider 账户中默认禁用、需要单独审批。
页面显式标出并禁用提交，**不提供任何"升级/购买/申请"入口** ——
那是被 SCOPE.md 排除的原站营销内容。
