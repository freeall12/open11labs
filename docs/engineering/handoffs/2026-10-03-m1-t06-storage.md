## 关键安全属性

1. **浏览器永不收到文件系统路径**。资产对外只有 `/api/v1/assets/:id`；
   测试断言 JSON 中不含数据目录或 `/Volumes`。
2. **路径由服务端生成**，按随机 id 分片，从不用文件名或提示词。
   `../../escape.mp3` 只作为显示名被展平，不影响落盘位置。
3. **原子写入**：临时文件 + rename，读者看不到半截文件。
4. **引用感知删除**：被工程引用的资产删除时抛 `REVISION_CONFLICT` 并列出引用者；
   删除工程则**保留**资产并明确告知数量。
5. **备份是双向不可信的**：
   - 导出：资产路径相对化、剥离任务输入快照（可能含用户文本）、无绝对路径
   - 导入：schema 版本必须匹配；路径穿越**硬失败**（不告警）；超限拒绝；
     含凭据形状的键**整体拒绝**而非静默剥离
6. **单用户本地模型**：Project 无 owner / member / role / workspaceId 字段（有测试断言）。

## 内容哈希 = 免重复生成

同一份字节再次导入（重新下载）解析到同一资产，`created=false`。
这正是 `specs/BYOK.md` 要求的「产物下载失败重下同一结果，不重生成」。

## 补齐：预算预留原子性

上轮记录的缺口——`checkBudget` 是咨询式检查，并发可超支。
新增 `createJobWithReservation()`：在 `BEGIN IMMEDIATE` 事务内
**重查预算 + 创建 job + 写入成本**，任一步失败整体 ROLLBACK。
测试证明：第二次预留被拒时**不留下 job 记录**。
未定价的预留记为 `unknown`（amount 为 null），不会变成 0。
