# 开源与资源许可

用户要求准备开源本地版，尚未要求对外发布。自有代码建议MIT，但D2未确认，当前未新增LICENSE宣称许可已经生效。实施Agent需在确认后加入正式LICENSE、版权归属与第三方通知。

本项目独立开发，不隶属或由ElevenLabs背书。名称/Logo/字体/音视频/缩略图/名人音色可能有独立权利，不能因研究或UI复刻而自动采用项目许可证。

- raw `research/`因账号标识与原站素材私有；只公开脱敏摘要/官方链接/合成测试资源。
- Waldenburg等字体无授权不打包；只用合法fallback并登记差异，不宣称字形完全一致。
- 图标使用可分发开源资源或自绘，记录来源/许可证；不引入不明确授权的生产资源。
- BYOK不解除Provider商业许可/身份克隆/肖像/音乐版权与模型审批条件；用户生成内容仍需依法使用。
- 社区数据/市场曲目/账户项目不能用作公开fixtures。所有测试素材为自有/已授权/合成。
- 引入ffmpeg/模型/SDK依赖检查分发与商业使用条件，并记录精确版本；不能泛称“全部MIT”。

合法资源公开目录为public/assets、public/fonts；加入前记录来源、许可、用途及可分发依据。发布门禁未完成不自动push或上传。

制作文档期间发现并行Agent提交b015698已加入原站Waldenburg字体与提取资源。本任务没有改动/删除这些既有文件，亦未核验授权；将其列为发布许可待核验项，不因已被Git追踪或build成功就判定可开源分发。授权未证实前不得打包公开发行，处理方式由发起者确认。
