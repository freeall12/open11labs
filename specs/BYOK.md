# BYOK 与任务产品规则（R3/R4/R5/R7）

本地BYOK/存储/任务配置保留；原站账户、套餐、积分、充值、收款及登录系统排除。具体技术见 [安全](../docs/architecture/security.md) 与 [契约](../docs/architecture/contracts.md)。

## Provider与钥匙

1. 无钥匙可浏览/编辑本地项目；真实生成禁用并指向本地Provider设置。
2. 用户自行选择Provider并输入已有钥匙；本地显示名称、掩码、验证时间和状态，不回显完整密钥。
3. 验证仅做明确低成本、无生成的认证/能力查询；验证不自动调用TTS/音效/图像。
4. 状态：未配置、未验证、验证中、可用、认证失败、权限不足、网络错误、已移除；无网络不等于无效钥匙。
5. 轮换不影响已保存资产；运行任务使用提交时的credentialRef，不静默迁到别的Provider；钥匙移除不能保证远端任务停止。
6. 默认会话内存；持久钥匙保存须明确用户选择，并使用OS钥匙串或用户主口令加密。主口令不可与密文同文件保管。D9待确认。
7. 支持本地模型Provider可作为扩展，但不会因此自动获得ElevenLabs专有模型效果。

## 能力与参数

`available / unavailable / unverified`三态；未知不能当支持。模型ID、参数、限额、输出格式和审批条件由Provider适配器提供。显示模型不能保证钥匙可用；不支持给中性原因，不显示升级CTA。用户必须知道实际调用的供应商、模型和发送的数据。

## 成本与确认

- 使用用户自己的Provider费用，不展示原站账户积分/套餐。
- 请求前显示预估值/计量单位/来源/有效时间；无可靠价格时明确“未知”。本地预估不是供应商冻结/报价保证。
- 示例/建议/模板/Agent调用凡会生成，先确认数据发送和可能费用。用户可显式开启知情快捷模式，但默认关闭。
- 未取得测试预算授权，不对研究网站或真实API进行付费测试。可用受控mock验证任务，UI必须标“演示/模拟”。
- 账本区分 estimated / reported / reconciled / unknown，单位币种不能混加；用量单位与金额不等价。失败/取消也可能计费，未知不填0。
- 预算仅限制本地应用发起新任务，不控制供应商账户其他客户端。并发预算预留须原子；未知估价超出控制能力时要求逐次确认，不能保证绝不超额。

## 任务状态与恢复

`draft → queued → submitting → running → succeeded / failed / unknown_submission`。
取消路径为 `cancel_requested → cancelled`（远端明确确认）或继续running/unknown。进程重启后按远端requestId/generationId查询，不重新生成。

- 提交前断网：保留草稿/排队，可由用户重试。
- 提交后超时：如果不能证明未被接受，则unknown_submission；先查询/对账再人工确认重试。
- 429：遵循Retry-After；查询可退避，付费提交不因429/5xx自动无限重发。
- 401/403：显示钥匙/能力问题，禁止循环；用户重新配置后主动重试。
- 供应商拒绝/空产物/格式错：标失败，不给假下载；保存原因和费用状态，不泄露敏感正文。
- 磁盘满/下载失败：保持远端成功与本地资产导入失败两个事实；允许重下同一成果，不重生成。

## 首条端到端验收链

无账户注册→本地设置钥匙→验证/能力→TTS选Provider/模型/音色→输入→确认→任务→播放→下载→保存历史→刷新与重启恢复。费用状态和requestId可追溯；不同Provider不得被静默替换。
