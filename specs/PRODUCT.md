版本 v0.1，2026-10-02。用户已明确目标；本文件补充方案为**待确认草案**，技术评审未执行，验收未运行。产品决策人：项目发起者；工程责任：CORE；验收组织：QA。来源：[最新交接目标](../AGENTS.md)、[代码与研究基线](../docs/research/coverage.md)、[官方资料](../docs/research/official-sources.md)。

## 1. 边界先行

### 最终范围

- ElevenCreative 应用中已发现的**创作工具**一级页面、相关子页面、主要弹层和操作状态，包括研究尚未覆盖的创作工具。原站全部营销与账号相关内容明确排除，见 [SCOPE.md](SCOPE.md)。
- UI布局、层级、参数区、数据列表、编辑器、导航和交互高度一致；必须维护逐控件清单并补足证据。
- 本地运行、本地项目/素材/历史存储、用户自带供应商密钥，真实生成与导出；可供开源发布的代码、文档和合法示例。

### 不偷换概念

| 不包含或不能保证 | 原因 | 如何呈现/何时重启 |
|---|---|---|
| 复制ElevenLabs专有模型权重/离线运行 | BYOK只是用户账户调用 | UI和存储本地，云推理明示；完全离线须选择独立本地Provider，不承诺同效果 |
| 云平台付款、权益、创作者收款、市场曲目交易 | 用户明确排除营销/账号相关内容 | 彻底移除页面/菜单/按钮，不留外链或占位 |
| 盗用商标/字体/图片、真实账户项目与密钥 | 开源不可公开未授权资源/隐私 | 使用合法可替换资源，记录视觉例外；授权后再替换 |
| 复制云端真实数据、社区和权限关系 | 本地默认单用户 | 本地合成fixtures或真实本地项目；多人自托管需独立鉴权设计 |
| 任意模型完全相同随机输出 | 模型随机性、版本/权限不同 | 验收API兼容与输出质量，不承诺二进制结果相同 |
| 同一阶段完成所有模块 | 需要依赖和补采 | M0–M5分期仅是执行顺序，完整范围不删减 |

用户最新指令已确认：营销横幅、升级引导、推广/销售、账号登录/注册/个人资料、云工作区/成员/角色、订阅/余额/充值/收益均排除。参考截图需裁剪或遮蔽这些区域后再验收；不保留空白占位。保留本地BYOK密钥配置、存储及任务/成本信息，不实现用户账户系统。品牌、未开放功能与替代字体例外仍需单独确认。

## 2. 用户价值与成功口径

用户为熟悉 ElevenLabs 的创作者、希望自行管理供应商成本和素材的本地使用者、接手开发的开源贡献者。服务端推理请求可能发送文字/音频/图片到供应商，不能宣称内容完全不离开设备。

没有真实使用量/转化数据。本轮139张截图和98条动作是研究投入，不是活跃用户或产品成功数据。

- 功能覆盖率：有证据与实现并通过验证的操作数 / 冻结范围内操作总数；未知、禁用和例外分别统计。
- 路由覆盖率：深链/刷新/返回通过的路由模式数 / routes.json 中本阶段路由模式数。
- 视觉覆盖率：通过同条件对比的状态截图数 / 约定状态截图总数；字体/数据/授权例外另报，不从分母偷偷扣除。
- 端到端成功率：真实发起任务中产出可播放/可下载目标成果且有费用状态的任务数 / 所有发起任务数；超时、拒绝、空产物必须计入。
- 安全约束：无密钥泄露、无隐式扣费重试、无未授权发布/克隆。任何一次违反不得以平均分抵消。

阈值/样本量及试运行窗口见 D4/D5/D6，未确认前不能宣布正式验收通过。

## 4. 主流程及状态

### 首次使用

启动本地应用→显示首页真实空态/合成演示标识→Provider设置→选择供应商→输入密钥→低成本验证→显示可用模型/权益→进入工具→输入/上传合法素材→显示预计成本/未知和供应商→用户确认→任务→查看/播放→下载或进入编辑器→历史自动保存。

无密钥仍能浏览完整UI和本地素材，但所有真实生成明确禁用并可进入设置。演示模式不能虚构远端成功、余额或费用。

### 六类状态

| 状态 | 用户看到什么 | 动作/保留与恢复 |
|---|---|---|
| 空态 | 无项目/音色/素材/密钥说明，适配本地账户 | 可导入、创建、配置；不会自动向云请求生成 |
| 默认 | 已选Provider/模型可用且输入有效；有记忆值时恢复 | 初次默认使用已验证能力，找不到默认模型要求选取，不静默替代 |
| 极限 | 文件/字符/时长恰好到上限、越界、格式不符 | 上限取该模型能力；客户端预检与服务器一致；不因名称相同共用上限 |
| 冲突 | 切换图像/视频/口型、不同Provider、双标签编辑冲突 | 保留兼容输入；不支持字段提示并移出提交参数；草稿分别保留，未提交内容不丢 |
| 异常 | 网络、401/403/429/供应商拒绝、提交结果未知、磁盘满 | 用户可理解的原因、费用未知状态、可恢复草稿；禁止自动重发有可能成功的付费请求 |
| 恢复 | 刷新/进程重启/重新连网/换钥匙 | 恢复本地任务ID和远端关联查询；无法查询标未知并人工确认；不得无限轮询/复制任务 |

技术实现、错误码与任务协议在架构文档中，不嵌入PRD。成本闭环见 BYOK spec。

## 5. 跨页面规则

- URL深链、前进后退、刷新、子路由和弹层查询参数语义一致；未保存修改离开需要提示，列表过滤参数与编辑草稿分开。
- 全局播放器不因普通页切换丢失；只有用户停止/隐藏/切换音频才改变播放状态，不自动播放供应商音频。
- 上传不等于授权自动生成；示例/模板可能原站直接生成，本地必须在付费前确认（差异 E1），除非用户显式开启知情快捷模式。
- 新建记录需要知道是草稿还是持久化；Escape不应假装撤销已经保存的对象。删除/分享/发布属于独立动作。
- 默认单用户本地数据；移除分成/云协作及账户所有者/角色/创建者筛选，不硬编码研究账号。

## 7. 明确的本地差异

E1 付费示例/建议按钮先确认；E2 原站营销、账号/订阅/收款/云工作区内容彻底移除，无占位/失效菜单/跳转；E3 合法字体/合成内容替代；E4 Provider/存储设置及任务状态是本地扩展；E5 默认关闭公共分享/遥测。以上差异必须登记，视觉复刻目标不能否定安全。

## 8. 评审自问

- 为什么不直接使用浏览器中的ElevenLabs登录？因为登录凭证不等于公开API许可且会泄露用户账号。
- 为什么部分创作操作仍可能禁用？因为能力受公开API与用户Provider钥匙权限约束；给出能力原因，不显示升级/订阅推广，不伪造成功。被排除的营销/账户按钮应彻底移除，不能用禁用占位代替。
- 为什么不是所有生成都自动重试？因为超时不等于没提交，重复请求可能重复收费。
- 为什么先做TTS通路？它验证密钥、任务、成本、播放器、导出和历史的共用链；其余模块复用，不缩减最终范围。
- 为什么不能叫绝对一比一已完成？因为参考覆盖、授权资源、模式效果与业务例外仍有待确认和验收。
