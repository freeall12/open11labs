- 代码基准：qa worktree HEAD `7ed2f05`，`src/features/voice/StsPage.tsx` + `VoicePicker.tsx`。
- 规范：`specs/pages/voice.md#变声器行`（证据 099–103）。
- 证据：routes.json `sts` → `100-voice-changer-form`（coverage: observed）。

## 页面状态

- **默认**：Provider 同 TTS 选取逻辑；队列为空；模型=Multilingual STS v2；参数 稳定性 0.5 / 相似度 0.75 / 风格 0；噪音移除关；费用确认未勾。
- **加载**：Provider 读取中提交禁用「正在读取本地 Provider…」。
- **空**：队列为空 → 虚线空态「队列为空。上传或录制音频后会显示在这里。」。
- **错误/拒绝**：非音频文件与超限文件**不静默丢弃**，聚合为「已跳过：…」提示；录音授权失败提示改用上传；转换失败显示 ApiError；同队列重复文件提示「已复用对应任务，不会重复计费」。
- **禁用原因链**（转换按钮）：加载中 → 无 Provider → 非 available → 队列空 → 未选音色 → 未勾费用确认 → 处理中。
