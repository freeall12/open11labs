## 每页必须提交的补充

每个独立页面/编辑器在实现前建立控件登记表（可在对应规范增补），字段至少包括：稳定操作ID、标签/aria、页面状态、入口/位置、输入、默认值、校验边界、点击/键盘/hover结果、弹层关闭、草稿持久化、副作用/费用、公开API或本地操作、证据ID、测试ID、已实测/待验证/不支持状态。

不可将同一页面所有按钮归为“正常工作”。原始 buttons.csv 的去重控件记录不能直接转为“已验证”的按钮需求。列表行的同构按钮可按类型登记，但抽查的样本/权限/禁用状态必须记录。

## 来源标签

- `实测`：观察到响应，不等于所有组合或后台提交已测。
- `文档`：API/能力来源；标链接和日期。
- `本地提案`：因本地化需要设计的交互，不能伪称原站。
- `待补采`：必须在视觉精确验收前补足，不得随意填造。

正文中的共享规则是实施规范草案；凡上限未有证据，不自行发明。`capabilities` 应提供运行时边界，文档中的观察值只作为测试案例，不写死为所有模型永久上限。
